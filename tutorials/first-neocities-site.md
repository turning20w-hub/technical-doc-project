# Create your first Neocities website

## What you'll learn

In this tutorial, you'll learn how to create a basic website on Neocities.

## Step 1 — Create an account

Go to Neocities and create an account.

## Step 2 — Open the site editor

After signing in, open your site's editor.

## Step 3 — Create your HTML file

Create a file called:

`index.html`

This will be the homepage of your website.
