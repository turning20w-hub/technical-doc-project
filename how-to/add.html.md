# Add HTML to a Neocities website

## Before you begin

You need a Neocities account and access to your site's editor.

## Add an HTML file

Create a file called:

`index.html`

Add your HTML to the file and save it.

## Example

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>

<h1>Hello!</h1>

<p>Welcome to my website.</p>

</body>
</html>
